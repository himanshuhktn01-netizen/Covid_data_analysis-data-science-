# 🦠 COVID-19 Data Analysis using Python

## 📌 Overview

This project analyzes global COVID-19 datasets to uncover trends in confirmed cases, deaths, and recoveries across different countries. It demonstrates data preprocessing, exploratory data analysis (EDA), statistical analysis, data transformation, and visualization using Python.

The project provides insights into the progression of the pandemic by calculating mortality rates, recovery rates, daily case trends, monthly summaries, and country-wise comparisons.

---

## 🚀 Features

- Data cleaning and preprocessing
- Missing value detection and handling
- Time-series analysis
- Country-wise COVID-19 trends
- Daily new case analysis
- Mortality rate calculation
- Recovery rate analysis
- Province-wise death rate analysis
- Data merging and transformation
- Monthly COVID-19 trend analysis
- Automated visualization functions

---

## 📊 Analysis Performed

- Top countries by confirmed COVID-19 cases
- Daily new cases for selected countries
- China COVID-19 case trend
- Country-wise mortality rates
- Recovery rate comparison
- Province-wise death rate in Canada
- Monthly confirmed, death, and recovery trends
- Countries with highest average death rate
- Countries with highest average recovery rate
- Recovery vs Death comparison for any country
- Monthly recovery ratio visualization
- Comprehensive merged COVID-19 dataset for analysis
